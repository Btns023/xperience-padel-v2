## Traitement 1 — Gestion des inscriptions et des groupes

| Rubrique | Contenu |
|---|---|
| Finalité | Enregistrer les demandes, constituer les groupes de niveau, planifier les séances, communiquer avec les inscrits |
| Base légale | Exécution du contrat (art. 6.1.b) |
| Personnes concernées | Titulaires de compte, joueurs adultes, joueurs mineurs (via leur représentant), responsables d'équipe / d'entreprise |
| Catégories de données | Identité, coordonnées (e-mail, téléphone, adresse), date de naissance, niveau de jeu, appartenance à un groupe, présences aux séances (facultatif) |
| Données sensibles | Aucune (aucune donnée de santé collectée) |
| Destinataires | Administrateurs de l'ASBL ; coach concerné (accès limité à ses groupes, sans montants) |
| Sous-traitants | Supabase (hébergement base + authentification, UE) ; Vercel (hébergement application, UE) ; Resend (envoi d'e-mails) |
| Transferts hors UE | Aucun |
| Durée de conservation | Pendant la relation, puis 3 ans après la dernière activité |
| Mesures de sécurité | Authentification, cloisonnement par rôle (Row Level Security), chiffrement des flux (HTTPS), accès nominatifs |

## Traitement 2 — Facturation et suivi des paiements

| Rubrique | Contenu |
|---|---|
| Finalité | Émettre les factures et notes de crédit, suivre les paiements par virement, relancer les impayés, tenir la comptabilité |
| Base légale | Exécution du contrat (art. 6.1.b) ; obligation légale comptable et fiscale (art. 6.1.c) |
| Personnes concernées | Payeurs (particuliers et entreprises) |
| Catégories de données | Identité et adresse de facturation, raison sociale et n° de TVA éventuel, montants, communication structurée, historique de paiement et de relances |
| Destinataires | Administrateurs ; expert-comptable de l'ASBL |
| Sous-traitants | Supabase (UE) ; Vercel (UE) |
| Durée de conservation | 7 ans (législation comptable belge) |
| Mesures de sécurité | Idem traitement 1 |

## Traitement 3 — Communication et notifications

| Rubrique | Contenu |
|---|---|

## Traitement 4 — Droit à l'image

| Rubrique | Contenu |
|---|---|
| Finalité | Utiliser des photos / vidéos des joueurs pour la communication de l'ASBL |
| Base légale | Consentement (art. 6.1.a), recueilli joueur par joueur, séparément de l'inscription |
| Personnes concernées | Joueurs (consentement donné par le représentant pour les mineurs) |
| Catégories de données | Réponse oui / non ; images produites le cas échéant |
| Retrait | Possible à tout moment par e-mail ; sans effet sur l'inscription |
| Durée de conservation | Jusqu'au retrait du consentement ou la fin de la relation |

## Droits des personnes

Accès, rectification, effacement, limitation, opposition, portabilité : demande
par e-mail à **info@padelxp.be**, traitée sous un mois. Réclamation possible
auprès de l'Autorité de protection des données (autoriteprotectiondonnees.be).

## Violation de données

En cas de violation susceptible d'engendrer un risque pour les personnes :
notification à l'APD dans les 72 h et, si le risque est élevé, information des
personnes concernées.
